# Official AgentVigil/WebSentinel Data

This directory contains only data and literal artifacts extracted from the official AgentVigil/WebSentinel repository. It intentionally does not vendor the official runtime implementation.

- `new_seeds.json`: exact seed values from official `new_seeds.py`.
- `text_seeds.json`: exact seed values from official `seeds.py`.
- `mutation_prompts.json`: exact mutator system prompt and mutation templates from official `mutate_prompts.py`.
- `adaptive_attack_data.json`: official dataset copied unchanged.

The JSON artifacts include the SHA-256 of the official source file they were extracted from.
